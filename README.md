# Publish to Web

Publish to Web tool for Chathackers Matrix chat integration tools.

This tool publishes posts from your group to the web, when you react to a post with the 🌐 emoji. 

## Getting started

1. Clone the repo
1. Run the command `npm install`
1. Run the command `npm run dev`
1. Copy the `publish.json` file and paste into the `registrations` folder of [the wrapper project](https://github.com/chat-hackers/tool-hub)
1. React to a message in your whatsapp group with the 🌐 emoji to publish to web
1. Marvel in delight at your newfound power
